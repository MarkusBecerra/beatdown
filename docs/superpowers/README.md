# `docs/superpowers/`: records of the agent-driven build

Working documents from building beatdown with AI agents, using the "superpowers" agent-workflow skills that the folder is named after. They record how the code came to be, not how it works today.

- [`plans/`](plans/README.md) holds the v1 implementation plan (16 tasks) and the decision log kept while executing it: rulings, tasks added mid-way, and findings that were deferred. It also explains the labels code comments use to cite their origins (`Task 18`, `Ruling R-F`, `Finding 3`, `A2`, …).
